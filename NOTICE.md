# Attribution and included materials

These university lab projects were developed by a student lab team using course-provided RISC-V baseline material for Ben-Gurion University's Advanced CPU Architecture and Hardware Accelerators laboratory.

Several source files retain copyright notices naming **Hananya Ribo** and BGU. The repository also contains the original Intel/Altera-generated PLL wrappers and references Intel `altsyncram` primitives. Existing source-file notices are preserved. Benchmark assembly and memory images are identified as course materials in the source manifest.

Intel tools, simulator executables and compiled vendor simulation libraries are not distributed. Use your own licensed installation.
